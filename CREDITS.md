# Credits

RDM is free software under the MIT license. It stands on the work of these
projects - thank you to everyone who builds and maintains them.

## Inspiration

- Internet Download Manager (Tonec Inc.), whose interface and workflow RDM follows. RDM is an independent project and contains no IDM code. - https://www.internetdownloadmanager.com

## Helper programs (installed on request, not bundled)

- yt-dlp (Unlicense) - downloads from YouTube and many other video sites - https://github.com/yt-dlp/yt-dlp
- FFmpeg (LGPL/GPL) - joins video and audio streams, converts audio - https://ffmpeg.org

## Libraries

- egui and eframe (MIT or Apache-2.0) - the user interface - https://github.com/emilk/egui
- wgpu (MIT or Apache-2.0) - graphics on Windows - https://github.com/gfx-rs/wgpu
- winit (Apache-2.0) - windows and input - https://github.com/rust-windowing/winit
- tray-icon and muda (MIT or Apache-2.0) - system tray icon and menu - https://github.com/tauri-apps/tray-icon
- tokio (MIT) - asynchronous runtime - https://github.com/tokio-rs/tokio
- reqwest and hyper (MIT or Apache-2.0) - HTTP client - https://github.com/seanmonstar/reqwest
- rustls and aws-lc-rs (Apache-2.0, ISC, MIT) - TLS - https://github.com/rustls/rustls
- librqbit (Apache-2.0) - BitTorrent - https://github.com/ikatson/rqbit
- RustCrypto aes, cbc and sha2 (MIT or Apache-2.0) - HLS decryption, checksums - https://github.com/RustCrypto
- serde and serde_json (MIT or Apache-2.0) - settings and download list - https://github.com/serde-rs/serde
- tiny_http (MIT or Apache-2.0) - local endpoint for the browser extension - https://github.com/tiny-http/tiny-http
- rfd (MIT) - native file dialogs - https://github.com/PolyMeilex/rfd
- arboard (MIT or Apache-2.0) - clipboard - https://github.com/1Password/arboard
- chrono, url, directories, open, thiserror and many more small crates - https://crates.io
